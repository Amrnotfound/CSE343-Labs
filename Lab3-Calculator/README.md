# iOS Calculator - CSE343 Lab 3

A simple calculator webpage built with HTML, CSS and JavaScript for CSE343 Web Development (Section 3), Ain Shams University.

**Author:** Amr Ahmed Hashem (24P0417)

## Features
- Addition, subtraction, multiplication and division
- Percent, decimal point, `00` and AC (clear) buttons

## Files
- `index.html` - page structure
- `style.css` - iOS-style design
- `script.js` - calculator logic

## How to run
Open `index.html` in any browser, or use the Live Server extension in VS Code.
